WAMC · Where Are My Clothes

A phone app that remembers where each garment is kept. I photograph it, write where it goes, and later search instead of opening every drawer.

Try the demo

Sample clothes, runs in your browser, nothing is saved.

The journey

Design

Black ink on white paper, heavy rules, one condensed typeface, and yellow only for what needs attention. It is made for one hand on a phone: every button is at least 44 pixels tall, and text fields use 16-pixel type so the iPhone does not zoom in.

Scope

One person, one wardrobe. It is a web page, so there is no app store and nothing to install. It keeps up to 2,000 garments, each with up to 200 dates of use. It does not plan outfits, share with other people or work offline.

How it is built

  1. The pageOne HTML file with plain JavaScript: no framework and no build step. Photos are shrunk on the phone before they are sent.
  2. The serverOne PHP file on ordinary shared hosting.
  3. The dataNo database. The list is a JSON file, written under a file lock so two saves cannot collide. Photos sit in a folder the web cannot open, and only a signed-in phone gets them.
  4. The lockOne password, stored hashed. The first visitor after installing chooses it. Five wrong tries lock the app for 15 minutes, and a sign-in lasts 90 days.
  5. The demoThe same page in English, with the server swapped for a pretend one inside the page, so anyone can try it without seeing my real wardrobe.
